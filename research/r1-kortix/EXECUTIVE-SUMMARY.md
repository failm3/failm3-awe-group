# Решение по AWE R1

Сохранить AWE/Mastra и существующие Head, Mission Manager, Factory, TI, Memory, QA. Внедрять один короткий квалификационный цикл вместо новой управляющей платформы. Исследование закончено; разрешение на внедрение и production PASS не выданы.

Уже есть документально подтверждённое R0 offline-ядро с lifecycle/recovery/grants и целостностью артефактов. Не доказаны восстановление final release, безопасное исполнение недоверенного кода, полная передача требований, профессиональная результативность, межмиссионное улучшение и полная цена результата. Полный аудит OpenCode прочитан; актуальные исходники напрямую недоступны. Его аудит не проверял старые 22 MD Kortix.

Первый R1: T0 inventory → T1 восстановление/R0 parity → T2 isolation и T3 immutable spec/ledger → T4 предметный QA → T4a минимальный qualification/admission/revoke → T5 локальная CSV-аналитика → T6 измеренный перенос. Research/code — следующие отдельные scopes. Browser/vendor/workflow не блокируют первый результат и подключаются только по доказанному gap.

Готовыми использовать native Mastra interfaces после проверки current wiring. Разработка сквозных contracts, security, qualification и QA существенна; сроки/цена и runtime-совместимость не установлены. Не покупать connector bundle/vector database/orchestration platform заранее.

После успешного R1 будет доказана только ограниченная способность на конкретных procedure/model/tools/environment и новых cases, с независимой приёмкой, revoke и полным ledger. Каталог расширяем без фиксированного потолка; исполнение всегда ограничено. Сохранённые документы, роли и число агентов не доказывают компетенцию.

Независимый reviewer нашёл M1–M3 и m1–m2; выпускающий исправил порядок T4a, детерминированный CSV contract, ошибочную атрибуцию Composio и добавил runbook/source index. Полный disposition — REVIEW-DISPOSITION.md. Application tests и демонстраторы NOT_RUN. Следующий engineering GO требует отдельного допуска, разрешённого frozen source, restore evidence, safety/regression/compatibility tests и независимой предметной приёмки; текстом эти gates не закрыты.
