## Доступность канала и история

[Публичная витрина](https://t.me/s/iirepresent) открывается без входа и показывает тексты, внешние ссылки и ссылки отдельных публикаций. Часть видео обозначена как неподдерживаемая браузером либо требующая Telegram. Поэтому содержание публикаций подтверждено на уровне доступного текста, а не полного просмотра видеодемонстраций. [2] [3]

Изучены стартовая витрина и две контекстные страницы `/2589` и `/2584`. На них встретились публикации с ID от 2566 до 2602, но это не непрерывный архив. Навигация содержит параметры `before` и `after`; пригодный метод исторической выгрузки здесь — публичный HTML с сохранением ID и ссылок, без заявления о полноте Telegram API. Полный обход не выполнялся: за него отвечает отдельный коллектор. Точные даты публикаций из извлечённого текста не установлены. [2] [3] [17]

Канал содержит конкретные ссылки на навыки Claude Code, API и интеграции, но рядом идут развлекательные рекомендации и рекламные материалы. Его ценность — обнаружение кандидатов; технические характеристики необходимо переносить из официальных источников. Показатели подписчиков на страницах расходятся: посадочная страница дала 116 343, первоначальная витрина — округлённые 117K, контекстная — 116K. Эти значения не использованы как синхронная статистика. [1] [2] [3]

## Claudemy: открытый навык для аудиокурсов

В [публикации 2589](https://t.me/iirepresent/2589) имеется прямая ссылка на репозиторий `assafkip/claudemy`. Канал описывает персональную программу из 12 коротких диалоговых аудиоуроков и 40 источников. README автора уточняет: исследуются **20–40 страниц**, а число уроков — **примерно 12**, по две минуты. Эти числа следует хранить как описание типичного результата, не гарантированный контракт. [4] [5]

Официальный README описывает MP3 с двумя ведущими, карточки с идеей, упражнением и ссылками, сводный playbook и пробный урок перед созданием остальных. Автор также заявляет проверку, которая отклоняет ссылки на страницы, не прочитанные исследованием. Это описание механизма, а не доказательство фактической точности цитат или качества обучения. [5]

Интеграционный путь конкретен: плагин Claude Code либо каталог навыка `skills/claudemy`. Требуются Claude Code с веб-поиском, Python 3, `beautifulsoup4` и `ffmpeg`. ElevenLabs API используется для премиальных голосов; без него README описывает бесплатные системные голоса macOS. `pandoc` нужен только для дополнительной копии карточек в Word. Бесплатная озвучка на Linux или Windows не подтверждена. [5]

Лицензия самого навыка — **MIT**, проверена по файлу LICENSE. Она допускает изменение и распространение с сохранением уведомлений и предоставляет ПО без гарантий. Навык бесплатный, но пользователь оплачивает свой план Claude и, при выборе ElevenLabs, соответствующие кредиты. Точные цены этих зависимостей не проверялись. При ElevenLabs текст уроков передаётся этому провайдеру; без него аудио на macOS создаётся локально. [5] [6]

**Решение:** кандидат для дальнейшей проверки адаптера навыков. Установка, генерация уроков и проверка цитат не выполнялись; изученная ветка `main` не закреплена за конкретным релизом.

## MagicSlides: YouTube → PPT и документированный API

В [публикации 2584](https://t.me/iirepresent/2584) указан официальный конвертер YouTube To PPT. Его страница заявляет преобразование видео в PowerPoint с созданием, редактированием и скачиванием слайдов. Более подробная официальная API-документация поддерживает входы `youtubeURL`, тему, текст, PDF, веб-страницу и DOCX, а также параметры числа слайдов и языка. [7] [8] [9]

Для AWE наиболее конкретная возможность — REST-адаптер к `https://api.magicslides.app/public/api/ppt-from-text`: ключ `apiKey` передаётся в JSON, для видео используется `youtubeURL`, для количества слайдов — `slideCount`. Документированы ответы со ссылками на PPTX и PDF и примеры Python, JavaScript/TypeScript и cURL. Отдельное новое CLI-семейство на `www.magicslides.app` использует заголовок `x-api-key`; HTML Studio возвращает поток SSE. Эти способы аутентификации нельзя смешивать. Адаптер здесь не реализован и запросы генерации не отправлялись. [9]

Категория оплаты — **бесплатная квота плюс оплата использования**. Страница API-тарифов на дату чтения обещает 100 бесплатных презентаций ежемесячно, затем 0,50 USD за генерацию без месячного базового платежа. Однако API-документация отдельно указывает 0,50 USD за Editable/HTML Template и 1,00 USD за HTML Studio. Применимость общей бесплатной квоты ко всем новым CLI-методам не установлена; это также не тариф веб-конвертера. [10] [9]

Открытый официальный репозиторий и SPDX-лицензия не установлены. Это SaaS по Terms of Use IndianAppGuy Tech Private Limited. Раздел 2 ограничивает копирование и перепродажу частей сервиса без письменного разрешения, хотя API-документация предлагает встраивание генерации в продукты. Для перепродажи и специального размещения необходимо уточнить договорные права, а не считать наличие API разрешением на любые способы использования. [11] [9]

**Материальное противоречие:** API-документация перечисляет модели DeepSeek и Anthropic/Claude для HTML Studio, а Terms of Use утверждают, что DeepSeek, OpenRouter и Claude в сервисах не используются. Фактических обработчиков данных по этим страницам установить нельзя. До передачи чувствительных материалов требуется уточнение у поставщика. [9] [11]

**Решение:** кандидат с хорошо описанным REST-интерфейсом, но с нерешённым вопросом провайдеров. Работоспособность API, результат экспорта и обещание обработки любого видео не проверены.

## CapCut × ChatGPT: официальная интеграция с ограничениями доступа

[Публикация 2582](https://t.me/iirepresent/2582) называется «Подключаем CapCut к ChatGPT через Codex» и ведёт на официальный URL `capcut-x-codex`. На сайте продукт озаглавлен **CapCut × ChatGPT**, а FAQ прямо называет рабочий процесс официальным. Различие названий сохранено в записи, чтобы не создать два ресурса по одной ссылке. [12] [13]

Официально описаны генерация или загрузка материала, редактируемый черновик, правка сцен, таймлайна, текста, музыки, субтитров и эффектов в чате, а затем открытие проекта в редакторе CapCut. Страница называет техническую связь **CapCut MCP connection**. Это подтверждает заявленный интеграционный механизм, но не совместимость с произвольным клиентом AWE. [13]

Документированный путь относится к поддерживаемой задаче в desktop-приложении ChatGPT на PC, а не к чисто браузерному сценарию. Требуются установка и авторизация. На дату чтения страница указывает доступность за пределами США и будущее появление в США; она также оговаривает зависимость от версии приложения, аккаунта и региона. Доступ конкретного аккаунта не проверялся. [13]

Цена самого рабочего процесса и гарантированная бесплатная квота **неизвестны**. Официальный FAQ предлагает смотреть условия аккаунта, региона и продукта. Общие Terms of Service CapCut различают бесплатные и платные планы, но из этого нельзя вывести бесплатность плагина или всех его генераций. Точные суммы не установлены. [13] [14]

SPDX-лицензия и публичный официальный репозиторий интеграции не установлены. Условия CapCut сохраняют права на сервис и отдельно регулируют материалы. Наличие библиотеки «free assets» не доказывает неограниченные коммерческие права на музыку и другие компоненты. Прочитанная страница Terms содержит американскую редакцию; применимость условий к конкретному региону нужно уточнить. [14]

**Решение:** кандидат для отдельной оценки desktop/MCP-сценария. Опубликованная команда загрузки внешнего `SKILL.md` рассматривалась только как свидетельство пути установки и не исполнялась. Установка, авторизация, монтаж и генерация не проводились.
