## Agno — агентный runtime и интерфейс инструментов

[Публикация 3561](https://t.me/GitHubRadar/3561) ссылается на `agno-agi/agno` и описывает агентов, команды, постоянные сервисы, память и согласование действий человеком. Официальный README подтверждает агентные teams и workflows, AgentOS со встроенными API/MCP, память, планирование и трассировку.[3] [4]

Документированы три пути потенциальной интеграции с AWE: Python-функции и toolkits, подключение внешних MCP-серверов через `MCPTools`, либо отдельный AgentOS-сервис через REST. В руководстве API приведены `GET /agents` и `POST /agents/{agent_id}/runs`, а для развёрнутого сервиса рекомендованы PostgreSQL и pgvector. Инструмент можно пометить `requires_confirmation=True`, чтобы чувствительное действие ожидало решения человека. Это документированные возможности проекта; адаптер AWE не создан и совместимость не испытана.[5] [6]

Лицензия репозитория — **Apache-2.0**. SDK и AgentOS бесплатны; коммерческая оплата относится к control plane. На официальной странице Free стоит $0 в месяц и подключается к локальному AgentOS. Pro стоит $150 в месяц и включает одно live-подключение и три места команды; Enterprise рассчитывается индивидуально. Бесплатный runtime не означает бесплатную панель для live deployment. Расходы на модели и собственную инфраструктуру здесь не оценивались.[7] [8]

Agno подходит как кандидат на агентный слой благодаря явным программным интерфейсам. До одобрения и записанного live test он остаётся только исследованным кандидатом. README также описывает телеметрию, которую можно отключить через `AGNO_TELEMETRY=false`; локальное развёртывание само по себе не доказывает отсутствия сетевых событий.[4]

## Activepieces — коннекторы и управляемая автоматизация

[Публикация 3564](https://t.me/GitHubRadar/3564) содержит прямую ссылку на `activepieces/activepieces`. Официальный README подтверждает визуальные flows, циклы, ветвления, повторные попытки, HTTP и Code steps с NPM. Он также перечисляет Google Sheets, OpenAI, Discord и RSS и описывает self-hosting. Pieces — расширяемые интеграции на TypeScript, поэтому собственный коннектор к API AWE технически возможен, но не реализован.[9] [10] [11]

Документирован MCP-интерфейс для обнаружения действий, чтения их схем, построения flows и разбора запусков. Например, `ap_research_pieces` ищет pieces, `ap_get_piece_props` возвращает параметры действия, а `ap_list_runs` и `ap_get_run` дают сведения о запусках. Это делает Activepieces интересным кандидатом для каталога внешних операций. У него есть и изменяющие состояние инструменты, поэтому обнаружение возможностей нельзя считать разрешением на их выполнение.[12]

**MIT относится не ко всему монорепозиторию.** Основная лицензия исключает enterprise-каталоги и сохраняет лицензии сторонних компонентов. Для enterprise-кода действует отдельная коммерческая лицензия; production-использование требует действующей Enterprise license и соблюдения договора.[13] [14]

Категория оплаты — бесплатная self-hosted Community Edition плюс коммерческие планы. Официальная тарифная страница показывает Free $0, Plus $20 в месяц и Team $200 в месяц при месячной оплате. Ultimate и Enterprise control имеют индивидуальную стоимость; Embed начинается от $36 тыс. в год.[15]

Для API есть существенное расхождение: новая тарифная страница рекламирует `MCPs and API access` уже в Free, но API overview говорит, что выдача platform API keys для управления несколькими проектами доступна только в Platform/Enterprise. Поэтому бесплатный доступ к конкретному административному API не обещается. На тарифной странице также расходятся описания восстановления бесплатных credits: сравнительный блок говорит Daily, FAQ — о следующем месяце. Фактическое применение квот не проверено.[15] [16]

## Unstructured — подготовка документов и доказательств

[Публикация 3578](https://t.me/GitHubRadar/3578) ссылается на `Unstructured-IO/unstructured` и описывает извлечение данных из PDF, HTML и Word. Официальная документация открытой Python-библиотеки подтверждает partitioning: документ преобразуется в типизированные элементы, например заголовки, основной текст, списки и таблицы. OCR и извлечение таблиц зависят от формата, стратегии обработки и установленных зависимостей.[18] [19] [20]

Для AWE наиболее прямой потенциальный путь — локальный Python-адаптер к `unstructured.partition.auto.partition`, а затем `chunk_elements` или `chunk_by_title`. Последующая группировка элементов полезна для RAG, то есть поиска фрагментов документов перед ответом модели. Документация предупреждает, что при объединении часть метаданных теряется; `metadata.orig_elements` позволяет сохранить исходные элементы и их метаданные. Это особенно важно для происхождения доказательств, но конкретный pipeline AWE не построен.[20] [21]

Открытая библиотека распространяется по **Apache-2.0**, и README прямо объявляет её бесплатной. Коммерческий сервис — отдельный вариант: тарифная страница показывает 10 000 бесплатных страниц при создании аккаунта, затем $0.015 за страницу и индивидуальные Business-планы. Это начальная квота, не обещание ежемесячного бесплатного лимита.[19] [22] [23]

Коммерческие Transform и Pipelines доступны через REST и Unstructured Python SDK, причём документация прямо говорит, что **Pipelines продаётся отдельно от Transform**. Его точная цена неизвестна, поэтому тариф $0.015 нельзя автоматически переносить на Pipelines. Платная «страница» также не всегда означает физическую страницу: для ряда форматов её расчёт основан на объёме 100 KB.[24]

Локальная библиотека требует дополнительных пакетов и иногда Tesseract, Poppler, libmagic либо LibreOffice. README описывает телеметрию и её отключение через `DO_NOT_TRACK` или `SCARF_NO_ANALYTICS` до импорта. Качество OCR на русском языке и рекламные сравнительные метрики не проверялись.[19]

Заявления о числе подписчиков и мониторинге 320 источников не верифицированы. Подтверждённые репосты других редакционных каналов в просмотренном фрагменте не обнаружены.[1] [25]

В `GitHubRadar_research.json` массив `resources` содержит ровно три записи с полями контракта: возможностями, способами интеграции, ценовой категорией, лицензией, доказательными assertions и точным provenance. Неизвестные факты оставлены `null`. Все три имеют статус `documented` и решение `candidate`: это проверка официальных источников, **не функциональные тесты и не одобрение интеграции**. Успешное чтение веб-страниц и HTTP 200 не используются как доказательство работоспособности.
