Для каждой сохранена запись в `resources` с точными ссылками на посты, официальными подтверждениями, лицензией, категорией цены и ограничениями. Ни один инструмент не устанавливался, не запускался и не получил разрешения на исполнение. [1] [2] [3] [4]

Автор: Manus AI. Проверка источников: 12 ноября 2026 года.

## Herdr App: приоритетный кандидат для управления агентскими сессиями

[Пост 717](https://t.me/sachkov_blog/717) прямо ссылается на `herdr.dev` и рассказывает о новом полноценном приложении Herdr. Официальный сайт ведёт на `herdrdev/herdr-app`; README подтверждает настольную среду для терминалов и coding agents, где процессы выполняются в отдельном `herdr-core`. Это важно для идентификации: новое приложение и прежний **Herdr TUI используют разные серверы и не разделяют текущих агентов**. Нельзя переносить свойства одного runtime на другой без проверки. [4] [6] [7]

Документированы spaces и вкладки для задач, статусы через открытый протокол OSC 7501, удалённые машины по SSH и изменяемые JavaScript mods. Закрытие окна не прекращает работу core. Однако перезагрузка машины или остановка core завершают программы: автоматически продолжить работу агента приложение не обещает. Linux GUI требует графической сессии и работающего Vulkan-драйвера. [6] [7]

Для AWE наиболее содержательная возможность интеграции — **адаптер `herdr-core`**, а не имитация кликов по окну. Официальная документация перечисляет `hc run`, `send`, `wait`, `read`, `ls`; `hc schema` выдаёт OpenRPC-описание API со streams и events. Собственный процесс может сообщать статус через OSC 7501. Это подтверждённая поверхность интеграции, но совместимость с AWE и работа команд здесь не проверены. [8]

Категория цены — бесплатное открытое ПО. Основной LICENSE приложения — **Apache-2.0**; бесплатность самого Herdr не определяет стоимость выбранных LLM и агентских подписок. В релизах по умолчанию включена telemetry, а mods являются доверенным кодом без sandbox: подключать сторонние расширения автоматически нельзя. [6] [7] [9]

## Orca: агентская среда с worktrees и программным управлением

В [посте 702](https://t.me/sachkov_blog/702) автор описывает переход на Orca и ссылается на статью «Где работать с агентами: от терминала до ADE». В самой статье гиперссылка Orca ведёт на `www.onorca.dev`; авторская подборка из поста 687 связывает название с `stablyai/orca`. Поэтому идентифицирован именно этот проект, а не другое ПО с названием Orca. Статическая выгрузка статьи сначала вернула оболочку, но браузер прочитал её без входа через Telegram. [10] [11] [5] [12]

Официальный проект документирует параллельные CLI agents в отдельных Git worktrees, переключение между чатом и терминалом, просмотр diff, комментарии к изменениям, встроенный браузер и удалённое выполнение. Поддерживается подключение собственных агентских подписок, в том числе Claude Code, Codex и OpenCode. Репозиторий отдельно описывает связи с GitHub и Linear. Эти сведения подтверждены документацией, а не нашим запуском. [13] [14]

Для AWE возможен CLI-адаптер: документация перечисляет команды worktree, terminal и browser с JSON-выводом, а также skill `orca-cli`. Существенное ограничение — desktop CLI управляет **уже запущенным Orca editor**. Документированные Remote Orca Server и SSH заслуживают отдельной проверки для headless-среды; автоматически считать настольный CLI готовым backend API нельзя. Git worktree также не доказывает изоляцию прав исполняемого агента. [14] [15]

Категория цены — бесплатное открытое приложение с собственной подпиской на выбранного агента. Проверен основной **MIT LICENSE**. Enterprise-страница предлагает прямое обсуждение внедрения и поддержки, но не публикует числовой тариф и не позволяет установить платность предложения. Эти неизвестные оставлены `null`. Функция публикации artifacts создаёт публичные ссылки и не должна включаться для приватного каталога AWE без отдельного разрешения. Маркетинговое обещание «100x» не принималось как измеренный результат. [13] [15] [16] [17]

## Papermorph: конкретный skill для PDF и интерактивных учебных материалов

[Пост 688](https://t.me/sachkov_blog/688) содержит прямую ссылку на `DozenTwelve/Papermorph` и описывает превращение PDF-книги в веб-книгу с уроками, озвучкой, анимациями и квизами. Официальный README подтверждает этот тип workflow и расширяет его: есть установка skill для Claude Code и OpenCode, статические страницы без backend и базы данных, экспорт MP4/SRT и упаковка SCORM для систем управления обучением, LMS. [3] [18]

Для AWE это кандидат в skill/workflow-каталог, не готовый подтверждённый HTTP API. Документированы команда `/papermorph`, зависимости `uv`, `ffmpeg` и браузеры Playwright. Результат можно размещать как статическую папку. README также описывает Edge TTS или локальный Kokoro и необязательные платные API ElevenLabs, OpenRouter и OpenAI. Общая стоимость зависит от модели и выбранных шагов; авторские примеры затрат в README не используются как актуальные тарифы. [18]

В посте написано, что skill работает только с Opus 5.5. **Это ограничение не перенесено в текущую ресурсную запись:** официальный README уже говорит о выборе моделей на каждом шаге и приводит примеры разных моделей. Это расхождение между публикацией и текущей документацией, а не результат нашей проверки модельной совместимости. [3] [18]

Основной LICENSE — **MIT**, но README прямо уточняет границы: MIT покрывает код, встроенный MathJax имеет Apache-2.0, а изображения, записи и данные сохраняют отдельные лицензии. Права на входные книги и публичные производные материалы требуют самостоятельной проверки. Наличие открытого кода не делает чужой PDF или все демонстрационные медиа свободными для использования. [18] [19]
